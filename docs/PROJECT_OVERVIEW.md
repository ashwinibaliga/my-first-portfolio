# Project Overview

## Purpose

This project is a personal portfolio website for **Ashwini Baliga**, a Computer Science and Engineering student specialising in Artificial Intelligence and Machine Learning (CSE-AIML). The portfolio communicates her identity as an aspiring frontend developer, highlights her hackathon achievements and projects, and provides verified contact information for potential collaborators, peers, and recruiters.

## Goals

1. Present Ashwini's skills, projects, and achievements in a polished, professional format.
2. Communicate her personal brand: curious, continuously learning, frontend-focused, and interested in real-world problem-solving.
3. Showcase her HackAce 2.0 win and other hackathon participation.
4. Provide working links to her GitHub, LinkedIn, and email.
5. Produce a maintainable, well-documented codebase she can update independently.
6. Adhere strictly to verified personal information — no fabricated facts.

## Intended Audience

- Potential collaborators and peers
- Recruiters and hiring teams
- Hackathon organisers
- Anyone interested in her work or background

## Scope and Exclusions

**In scope:**
- Static single-page React portfolio
- All supplied personal content
- Dark/light theming
- Accessibility best practices
- Production build and documentation

**Out of scope:**
- Backend API or database
- Blog or CMS
- Third-party form submission service (e.g. Formspree)
- E-commerce or payment features
- Server-side rendering (SSR)

## Design Direction

Dark, futuristic, developer-focused. Purple/violet accent palette on a near-black background. See `docs/UI_UX_DESIGN.md` for full token and typography documentation.

## Constraints

- All personal information must be verified. No invention of facts.
- No backend. The contact form uses a `mailto:` action.
- No API keys or secrets in client-side code.
- Resume download hidden until a real PDF is provided.

## Definition of Done

- Portfolio website implemented and building successfully.
- All supplied personal details accurately represented.
- TypeScript compilation passes without errors.
- Production build succeeds.
- All ten Markdown documentation files exist and contain accurate content.
- Missing assets and limitations documented.
